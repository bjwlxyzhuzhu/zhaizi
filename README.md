# 宅兹 · 周秦出土文献智能研究平台（MVP）

依据《宅兹平台PRD_v1.1》与 10 张融合版效果图开发。前端 React 18 + TypeScript + Vite + Ant Design 5 + three.js（R3F）+ ECharts；后端 FastAPI + SQLAlchemy 2。

## 本机启动（开发）

启动后端前，在当前进程环境设置 `ZZ_BOOTSTRAP_PASSWORD`（至少 12 位，首次初始化使用）和随机的 `ZZ_JWT_SECRET`。Docker 部署则将两者填写在 `.env` 中。

```bash
# 后端（首次启动自动建表并写入演示种子数据，SQLite 位于 backend/data/）
cd backend
python -m venv .venv && .venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m uvicorn app.main:app --port 8000

# 前端（另开终端）
cd frontend
npm install
npm run dev        # http://localhost:5173 ，/api 代理到 8000
```

生产：`npm run build` 后，后端会直接托管 `frontend/dist`，访问 http://服务器:8000 即可；或使用 `docker-compose.yml` 的一体化容器（默认 SQLite，可选 PostgreSQL 16）。

## 初始化账号

首次创建空数据库时，须在运行环境设置 `ZZ_BOOTSTRAP_PASSWORD`（至少 12 位）。初始化账号使用该部署私有密码，源码不包含默认密码。已有数据卷保留原账号密码。部署后应修改初始化账号密码、停用不需要的账号，并导入真实协作用户。

## 功能对照（PRD P0）

- **账号**：登录错误不区分账号/密码；5 次锁定 15 分钟；首次登录强制改密；停用、重置密码、角色变更后旧令牌立即失效；JWT 2h + HttpOnly 刷新令牌 7 天。
- **管理后台**：用户筛选/新增/编辑/批量；Excel 模板（含说明页与下拉）→ 预览校验 → 导入 → 一次性下载初始密码清单与错误清单；积分调整/批量发放/流水导出；积分规则；任务模板；审计日志；系统设置（密钥加密存储、只显示后 4 位、L2/L3 送云端锁定为否）。
- **积分**：只增不改流水，余额 = 流水合计；预扣 FREEZE → 成功 UNFREEZE+CONSUME / 失败 REFUND；并发安全；每日上限；研究员/管理员免扣但记“影子消耗”。
- **研究智能体**：文献问答智能体与拓片释读智能体，分别关联平台资料库及自建知识库。检索 → 模型 → 引证核验 → 证据抽屉；库外问题拒答；内容安全拦截并退分；导出含引用报告。
- **知识库与训练**：后台创建知识库、录入或导入 TXT/Markdown、填写来源与分级、发布/停用资料并动态更新索引；支持重建检索索引及训练记录。当前为 RAG 与 TF-IDF 索引，不修改模型权重。
- **导航与首页**：顶部菜单高亮和二级下拉，原左侧菜单改为默认折叠的卡片入口；首页支持主题轮播及折叠服务卡片。
- **站内通知**：管理员按指定用户、角色/单位/身份群体或全体启用用户发送；预览收件人后确认，保存送达人数和审计记录。
- **资料库**：器铭库（检索、详情、图集、铭文、文献对读、在图谱中查看）、字形谱系（金文/石鼓文/小篆 + 粒子演变）、方言库（脱敏）、传世文献对读；L3 仅研究员/管理员可见。
- **研究员工作台**：五类数据录入（来源与分级必填）、Excel 批量录入、双人审核（不能审本人）、版本对比与回退、专家裁断（采纳/修订/否决，理由必填，结果进入检索为 B 级）、图谱编辑、任务审核自动发分并站内通知。
- **3D**：S1a 登录页何尊照片深度粒子 + “宅兹中国”金文粒子；S2 星空力导向图谱（Worker 布局、辉光、搜索飞行、双击展开、图例显隐、器—铭—字—音—义路径模式、2D 降级）；S3 宝鸡 12 区县地形光柱；S4 字形粒子演变。
- **驾驶舱**：默认宝鸡真实区县边界与离线高程模型、等比缩放、全屏、手动开启轮播、建设进度和深绿青铜综合运营大屏（仅管理员）。运营大屏包含 6 项核心指标与 10 个可视化面板，支持 7/14/30 天趋势、刷新、全屏和管理跳转。地图来源和管理操作见 [使用说明](docs/knowledge-and-map.md)。

已在本机跑通的验收用例：T1（100 行含 3 错）、T3（问题含 `#模拟超时` 触发失败并退分）、T4（余额 5 并发 10 次 → 5 成功）、T5、T6、T7、T8、T11、AUTH-4。

## 数据与服务配置

1. **模型接入**：在管理后台“模型与 API 设置”自行输入密钥和接口地址，可使用 `https://token.agentone.work/v1`，读取该分组可用模型或手动填写模型 ID。管理员均可操作。无密钥时为库内摘引，图像候选为字形库相近项，不声称完成视觉识别。
2. **检索**：开发环境用汉字二元组 TF-IDF 代替 pgvector 向量检索（同一接口 `retrieval.search`），接入向量模型后替换打分函数。
3. **图片**：何尊已使用真实藏品照片（正面、侧面、铭文拓片）。逨盘、大盂鼎、毛公鼎等仍为效果图裁切；把馆藏照片放到 `frontend/public/img/vessels/` 并在资料库“编辑”中改图片路径，或由研究员在录入表单直接上传。
4. **地图**：使用 DataV 宝鸡市行政区边界和 Mapzen / Tilezen Terrarium 高程，来源和口径在地图中可展开查看。凤翔县按现行名称显示为凤翔区。
5. **种子数据**：器铭为公开著录整理、释文为通行释文（多为节选）；方言条目、古音为示例数据；字形为字体渲染占位。演示前须研究员核校，并补足首批数据（器铭 ≥50、方言 ≥200、节点 ≥500）。
6. **引证准确率等可信度指标**：须研究员在“驾驶舱 → 建设进度 → 录入抽检记录”中填写，无记录时显示“暂无数据”，不填造统计结果。

## 验证

前端执行 `npm run build`；后端工具环境运行 `python scripts/admin_features_test.py`，使用临时数据库和随机初始化密码，核验权限、密钥脱敏、通知定向送达、知识库索引和智能体关联。`python scripts/local_smoke.py` 检查 API、页面资源、路由和登录。Actions 在构建镜像后执行同类检查，再发布 GHCR。
