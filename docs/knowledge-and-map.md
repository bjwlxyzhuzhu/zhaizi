# 管理员使用说明

首次使用空数据卷时，在部署环境填写 `ZZ_BOOTSTRAP_PASSWORD`（至少 12 位）。平台不会使用源码中预设的登录密码。升级已有数据卷时保持现有账号密码。

## 模型接入

管理后台 → 模型与 API 设置 → 使用 TokenOne 接口地址。自行输入分组密钥，点击“连接并读取可用模型”，选择服务商返回的模型 ID，再保存。也可手动填写模型名。根地址自动补 `/v1`，完整 API 基址不会重复添加。

密钥加密存储，读取设置仅返回末四位。读取模型列表不调用收费对话生成接口；实际生成是否计费由服务商决定。更换运行环境时保留 `ZZ_SETTINGS_KEY`（未指定时使用 `ZZ_JWT_SECRET`）及持久化数据卷。

## 智能体与资料更新

管理后台 → 智能体与知识库。创建知识库，添加正文或导入 UTF-8 TXT/Markdown，填写可追溯来源，选择分级与发布状态。将知识库关联到文献问答智能体或拓片释读智能体，并保存关联。已发布资料增量更新索引；停用资料退出检索。

“训练 / 重建索引”执行文本分段与检索索引构建，并保存资料数、分段数、耗时及操作人。实现采用中文二元组 TF-IDF 检索增强（RAG），不会训练或微调云端模型权重。模型微调需要另行配置服务商训练接口及合规数据集。未配置云端模型时，文字回答为库内摘引；图像候选为字形相近项，不声称完成视觉识别。

仅 L1 已发布资料参与云端问答，L2/L3 不发送云端。平台已有资料录入、双人审核和专家裁断流程仍按原权限执行。自建知识资料由管理员核对来源后发布，证据等级标为 C（辅助资料），不能代替原器和专家审定。

## 站内通知

管理后台 → 站内通知。可选择指定用户、按角色/单位/身份组合筛选，或明确选择全体启用用户。先预览人数再发送。多个群体条件取交集，停用账号被排除；收件集合发生变化时需重新预览。发送记录及审计日志保留发送人与送达数。用户在顶部铃铛查看，打开消息时刷新，后台每分钟轮询。

## 宝鸡地图与指标

行政区边界来源：<https://geo.datav.aliyun.com/areas_v3/bound/610300_full.json>，获取日期 2026-10-18。原始数据中的凤翔县按现行名称显示为凤翔区，边界仍使用该公开数据集。

高程来源：Mapzen / Tilezen Terrarium，AWS Open Data。161 × 161 离线采样网格，由 12 张 zoom=9 瓦片生成。米制高程作视觉夸张；区县标记展示汇总量，不代表每件器物的精确出土位置。来源与许可汇总：<https://github.com/tilezen/joerd/blob/master/docs/attribution.md>。可运行 `scripts/build_baoji_relief.py` 重建（工具环境需要 Pillow；线上不需要）。

三维地图实现参考 sc-datav 的投影与挤出呈现思路：<https://github.com/knight-L/sc-datav>（Apache-2.0），本项目保留现有 React 18 / Three.js 技术栈，未复制其页面、素材或四川地理数据。

大屏默认固定显示宝鸡地图，手动启用轮播后才轮换知识图谱和字形。运营视图采用与平台一致的深绿青铜风格，包含 6 项核心指标、10 个可视化面板、7/14/30 天趋势切换、刷新、全屏和管理入口。资料、用户、智能体、审核、区县资源、积分、模型消耗及通知指标均从平台记录汇总；报告导出不计入智能体调用量。未产生的比率显示横线，不生成评审成绩或虚构运营数据。没有抽检记录时保留空缺；年度目标值与实绩分开展示。初始化样例资料保留其来源标记，不应作为实地调查或已完成成果的证据。
